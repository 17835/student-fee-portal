## Project Overview

The Student Fee Portal was developed to provide a convenient way for students to view their school fee information and monitor their payment status. It brings essential fee management features together in one interface, helping students understand their financial obligations and keep track of their payments.

## Problem Statement

Managing school fees manually can make it difficult for students to track outstanding balances, payment deadlines, and previous transactions. The Student Fee Portal addresses this challenge by presenting fee information and payment records in an organised digital platform.

## Objectives

- Provide a centralised dashboard for student fee information.
- Display fee breakdowns, payment progress, and outstanding balances.
- Allow users to interact with a mock payment interface.
- Provide access to payment receipts and transaction history.
- Create a responsive and user-friendly interface.
- Demonstrate the practical application of frontend web development technologies.

## Key Features

- **Dashboard:** Displays a summary of student fees and payment progress.
- **Fee Breakdown:** Shows individual fees, amounts, and payment statuses.
- **Payments:** Provides a mock payment interface for demonstrating the payment workflow.
- **Receipts:** Provides access to payment receipt functionality.
- **Transaction History:** Displays recorded payment transactions.
- **Help and Support:** Provides a section for assistance.
- **Settings:** Provides application settings, including interface preferences.
- **Responsive Design:** Supports use across different screen sizes.
- **Light and Dark Modes:** Offers alternative interface themes.

## How to Use the Application

1. Open the [live Student Fee Portal](https://scintillating-lamington-f05ef5.netlify.app/).
2. Explore the dashboard to view the fee summary and payment progress.
3. Navigate to the Fee Breakdown page to review individual fees and their statuses.
4. Open the Payments page to explore the mock payment workflow.
5. Visit the Receipts and transaction history sections to view available payment records.
6. Explore the Help and Support and Settings pages.

**Note:** The payment interface is for demonstration purposes and does not process real financial transactions.
